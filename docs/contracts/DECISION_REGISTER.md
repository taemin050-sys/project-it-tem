### 명시적 실험/고도화 대기 — 성급히 동결 금지
- CopySet headline/subline/cta 출력 스키마는 v0.5에 존재. **합성 방식, 최종 UI 필드 분할, 항목별 길이 제한은 실험 후 결정**. 임시 단일 text 400자도 코드 미반영.
- VLM: MVP는 화장품 여부. 동일 제품·세트·오류/경고 UX는 추후 결정. ProductAnalysis에 is_same_product 추가 금지.
- 기능성 여부(bool)만 MVP 사용자 입력; 기능성 종류별 판정은 고도화.
- Model ID는 회의 참고 후보이지 생산 공급자·가격 확정이 아님.
- 1차 외부 공개 환경의 인증·권한·CORS·HTTPS와 실제 live 수용 범위는 별도 배포 의사결정.

### 이 레지스터의 정확성 원칙
합의(D) / 개선안(I) / 미정(H)을 혼용하지 않는다. 고도화(H)를 10/30 필수 완료 항목에 넣지 않는다. PM/영향 담당이 바꾸면 CHANGELOG 및 구현 영향/Fixture 확인 후 버전을 올린다.
