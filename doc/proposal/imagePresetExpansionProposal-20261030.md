# BeautyAI 화장품 광고 프리셋 확장 제안

작성일: 2026-10-30
상태: **제안 / 팀 협의 전 / 미구현**
기준: 기존 웹서비스 MVP와 이미지 PR #17의 A 템플릿을 변경하지 않는 후속 설계

## 1. 제안 배경

현재 이미지 모듈에 구현된 카피 배치는 중앙 고딕 **A 템플릿 1종**이다. 기존 시안 B/C는 디자인 실험이지 서비스에서 선택 가능한 프리셋이 아니다. A만 사용하면 제품과 광고 목적이 달라도 비슷한 결과가 반복될 수 있다.

목표는 화장품 광고의 반복되는 **장면 연출 패턴**과 **글자 배치 패턴**을 분리해 재사용하는 것이다. 한 번에 모든 조합을 구현하는 계획은 아니다.

참고: 사용자가 제시한 [게티이미지뱅크 화장품 검색](https://m.gettyimagesbank.com/search/%EC%9D%B4%EB%AF%B8%EC%A7%80/%ED%99%94%EC%9E%A5%ED%92%88?lv=&st=union&page=1&q=%ED%99%94%EC%9E%A5%ED%92%88). 이는 **패턴 조사 출처 후보**이며, 해당 페이지의 모든 이미지를 검수·분류하거나 사용권을 확보했다는 의미가 아니다. 유료 원본 이미지를 라이선스 확인 없이 서비스에 포함하거나 학습·생성 입력으로 재사용하지 않는다.

## 2. 구조 제안

1. **장면(Scene) 프리셋:** 배경·소품·조명·제품 연출의 의도와 제한. 예: 미니멀 히어로, 스튜디오 단상, 물·광택, 계절·식물, 컬러·텍스처, 그래픽·프로모션.
2. **배치(Layout) 프리셋:** 제품 영역·헤드·서브·CTA 좌표·최소 글자 크기·카피 여백. 현재 구현은 A 중앙 정렬 1종. 좌측 카피, 분할형, 하단 카피는 **구현 제안일 뿐 미구현**.
3. **출력 옵션:** CTA 보이기/숨기기 토글을 제안. 현재 합성기는 빈 CTA를 허용하지만 사용자 토글 UI나 제품 정책은 확정되지 않았다.
4. **공통 품질 조건:** 제품의 각도·비율·색·라벨 검토, 소품·제품의 텍스트 침범 방지, 실제 한글 글자 폭·대비 확인, 최종 1080×1350 PNG.

조합 예시: ‘계절·식물’ 장면 + 기존 ‘A 상단 카피’ 배치. 소품 위치를 텍스트 프롬프트에서 ‘가장자리’로 고정하기보다, 선택한 레이아웃의 텍스트 영역과 제품 보호 영역을 피하도록 이미지 쪽에서 정한다. 특히 현재 A의 상단 safe_zone은 **하단 CTA까지 보호하지 않는다.** 소품을 무조건 하단·좌우에 놓으라는 지시는 충돌할 수 있다.

## 3. 팀별 협의·역할 제안

| 담당 | 협의할 내용 | 아직 하지 않은 것 |
|---|---|---|
| 텍스트(김다혜) | 제품·카피 의미, 콘셉트, 무드, 소품의 의미 제안. 장면 좌표를 텍스트 고정 프롬프트에서 강제할지 재검토 | 프롬프트·스키마 개편 합의 없음 |
| 이미지(박지수) | Scene/Layout 프리셋 버전, 카피·제품·소품 배치 규칙, 생성 전 지시와 생성 후 품질 검토 | 프리셋 엔진·여러 레이아웃 구현 없음 |
| 서빙(이형기) | 프리셋 선택값 저장, 요청 스냅샷·revision/hash·중복 호출 정책, 이전 작업 재조회 | 새 HTTP 계약 확정 없음 |
| 프론트(권혁상) | 장면 선택·배치 선택·CTA 토글 UI, 미리보기 및 가독성 확인 | 프리셋 UI 구현 없음 |
| PM·평가(이태민) | 후보 범위·완료 기준·팀 일정·검증할 실제 샘플·인터페이스 변경 승인 | 팀 합의·승인 없음 |

**계약 원칙:** 처음에는 내부 설정으로 실험하고, 공개 DTO/HTTP 변경이 필요해지면 기존 `docs/interface_spec.md`와 담당자 동의·PM 승인 절차를 따른다. 텍스트 담당의 `ImagePromptOutput{concept,prompt,mood}`를 임의 변경하지 않는다. 기존 작업의 프롬프트 버전과 저장된 요청 fingerprint도 덮어쓰지 않는다.

## 4. 단계적 제안

| 단계 | 범위 | 완료 확인 |
|---|---|---|
| 0. 현재 MVP | 기존 A 1종, MPO·합성·승인→다운로드 실서비스 인수 우선 | 현재 TODO의 미완료 검증을 끝낸다 |
| 1. 첫 확장 | 장면 3종(미니멀·단상·계절/꽃) × 기존 A 배치 | 동일 제품으로 구도 차이, 제품 보존, 카피 가독성 확인 |
| 2. 배치 확장 | 좌측·분할·하단 카피 레이아웃을 선택적으로 추가 | 각 영역에 대한 제품·소품 침범 및 CTA 충돌 검증 |
| 3. 추천 | 제품·카피 의미와 맞는 프리셋 제안, 사용자 선택 우선 | 추천 이유와 실패·수정 가능성 확인 |

이 단계는 **출시 확정 일정이 아닌 제안**이다. 자동 소품 추천·연상어 사전·자동 품질 점수·비용 최적화는 현 MVP 필수가 아니다.

## 5. 팀이 결정할 항목

- 프리셋을 사용자가 직접 고를지, 추천 결과에서 고르게 할지
- 장면 3종 첫 후보, 사용할 소품의 허용·금지 기준
- 레이아웃마다 헤드·서브·CTA 최대 줄 수와 운영 폰트
- CTA 표시 토글의 기본값과 위치
- 장면과 레이아웃 설정을 요청·작업 원장에 어떤 버전으로 저장할지
- 실제 제품 사진으로 합격 판정을 내릴 담당자와 검증 표본
